night evidence panels, lime retrieval actions and coral emphasis. Existing
content, charts, original fictional records and route behavior remain native.

The owner selected C, Precise, for the footer. Its compact grouped native routes
sit left; real editable AI questions and the existing open newsletter form sit
right. Geist UI supplies 14px secondary links, 15px medium primary links and
16px controls/headings. Geist Mono supplies 12px category labels. The Newsreader
Atlas signature fades into the original PH research-cabinet artwork; a static
full-width names-only studio line is last. All actions retain 44px targets.

The existing shared browser components own provider URLs, state, consent,
subscription submission and catalog revalidation. The host owns routes,
identity, palette and source/fictional boundaries. Fonts come from the shared
footer's licensed font registry; no global page typography or runtime
dependency is added. Narrow layouts stack the columns and scroll the studio
line locally. Sample pages use the same identity at a smaller browser reading
density; their original parser fields remain unchanged.
