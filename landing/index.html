How it works

PH Catalog is a local-first research pipeline for collecting public Product Hunt records into one consistent analytical dataset. The importer normalizes product identities, follows canonical aliases, deduplicates repeated records, and saves resumable progress so a long collection run can continue after interruption instead of starting over.

The normalized records live in DuckDB for exploration and can be exported to compressed Parquet snapshots. Each snapshot carries provenance and verification checks so analysis can distinguish a complete, tested export from an incomplete scrape. The repository also includes a read-only analytics path for asking aggregate questions without turning the experiment into another hosted Product Hunt clone.

What the public demo proves

This site runs the same parsing and presentation path against three original fictional products. It demonstrates the shape of a catalogue record, the link between a product page and the analytical workflow, and the boundary between reproducible code and data that should remain local. No real Product Hunt catalogue, private database, or generated research snapshot is published here.

The synthetic fixture is deliberately small. It is evidence that the pipeline can be exercised safely, not a claim that three records reproduce the scale or messiness of the full local catalogue. The project’s tests cover importing, alias resolution, snapshots, recovery, analytics, and the refusal to overwrite a non-sample catalogue accidentally.

Who it is for

PH Catalog is useful to developers and product researchers who want a transparent starting point for local market analysis: studying launch patterns, comparing categories, testing enrichment ideas, or learning how to build a resumable public-data workflow without republishing the source dataset. It is an experiment and reference implementation, not a commercial analytics service.

Read the source and documentation on GitHub to inspect the pipeline, run the synthetic demo, and reproduce the verified local workflow.
