03 / Your machine, your chosen mart

Run Atlas locally.

The operational Atlas UI is a read-only local analytics interface. It needs an already-built analytics mart; the three-record source catalogue alone is not that mart.

Follow the repository’s site/README.md and internal-analytics documentation to prepare the mart and open the loopback UI yourself.

With the analytics mart already built

uv run python tools/serve_analytics.py --database data/analytics/catalog-analytics.duckdb --port 8765
